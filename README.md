## 🔀 Submitting a Pull Request

### 1️⃣ Find or Create an Issue

Before making a major contribution, check whether an existing issue already covers your idea.

🔗 [**View Existing Issues**](https://github.com/ITRecruitersachin/RecruitVerse/issues)

If no relevant issue exists, create one describing your proposed contribution.

### 2️⃣ Fork the Repository

Fork the repository to your GitHub account.

🔗 [**Fork ITRecruitersachin/RecruitVerse**](https://github.com/ITRecruitersachin/RecruitVerse/fork)

### 3️⃣ Create a Branch

Create a dedicated branch for your contribution.

```bash
git clone https://github.com/ITRecruitersachin/RecruitVerse.git
cd RecruitVerse
git checkout -b feature/recruitment-sourcing-guide
```

### 4️⃣ Make Your Changes

You can improve or add:

* Recruitment documentation
* Sourcing strategies
* Boolean searches
* X-Ray searches
* GitHub sourcing techniques
* AI recruiting workflows
* Recruitment frameworks
* Recruiter tools
* Talent intelligence resources
* Mermaid diagrams
* Charts and visualizations
* Examples
* Templates
* Learning resources

### 5️⃣ Review Your Contribution

Before submitting your Pull Request, verify that:

* Information is accurate
* Links work
* Examples are understandable
* Formatting is consistent
* No confidential information is included
* No candidate PII is exposed
* No misleading recruitment claims are included
* External resources are properly attributed where required

### 6️⃣ Submit a Pull Request

Push your branch and create a Pull Request against the `main` branch.

```bash
git add .
git commit -m "Add GitHub sourcing techniques"
git push origin feature/recruitment-sourcing-guide
```

🔗 [**Create a Pull Request**](https://github.com/ITRecruitersachin/RecruitVerse/compare)

Please use a **clear and descriptive Pull Request title**.

Examples:

```text
Add GitHub sourcing techniques
Improve Boolean search examples
Add AI recruiting tools
Fix outdated sourcing resource
Add technical recruiter workflow
Improve candidate screening guide
Add recruitment analytics framework
```

## 🧠 Contribution Principles

RecruitVerse follows a few simple principles:

> **Share knowledge. Improve knowledge. Verify information. Help recruiters grow.**

### ✅ DO

* Share practical recruiting knowledge
* Provide real-world examples
* Explain the reasoning behind a technique
* Cite reliable sources when appropriate
* Keep information current
* Improve existing documentation
* Share free or accessible resources
* Respect candidate privacy
* Use anonymized examples
* Help other recruiters learn

### ❌ DON'T

* Publish candidate personal information
* Upload resumes containing PII
* Share confidential client information
* Publish proprietary company information
* Misrepresent recruiting experience
* Promote fraudulent recruitment practices
* Encourage discriminatory hiring practices
* Publish intentionally misleading information
* Spam the repository
* Upload copyrighted material without appropriate rights

---

## 🔐 Privacy & Candidate Data

**Never upload real candidate personal information.**

Do not commit:

* Phone numbers
* Personal email addresses
* Home addresses
* Driver's license information
* Passport information
* Visa documents
* Immigration documents
* Social Security Numbers
* Date of birth
* Confidential resumes
* Client-confidential information
* Proprietary recruitment data

Use **fictional, synthetic, or anonymized examples** whenever candidate data is required for educational purposes.

## 🏆 Contribution Quality Standard

Every contribution should aim to be:

**Accurate → Practical → Reproducible → Ethical → Useful**

If you are sharing a sourcing technique, provide an example.

If you are sharing a tool, explain what it does and where it can be useful.

If you are sharing a Boolean string, explain what it searches for.

If you are sharing an AI workflow, explain the:

**Input → Process → Output → Expected Result**
